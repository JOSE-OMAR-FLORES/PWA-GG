Sin Conexión

No hay conexión a internet disponible en este momento.

⚡ Pero no te preocupes, puedes seguir usando la app si la habías abierto antes. La PWA funciona sin conexión gracias al caché inteligente.

💡 ¿Qué puedes hacer offline?

  • Ver la página de inicio (App Shell cacheada)
  • Navegar por secciones descargadas anteriormente
  • Usar el gestor de tareas (datos locales)
  • Ver imágenes cacheadas
  • Acceder a funciones sincronizadas localmente
  • Guardar cambios temporales hasta que vuelva la conexión
  • Consultar datos que ya habías descargado
  • Usar todas las funciones básicas de la aplicación

❓ Preguntas Frecuentes

¿Perderé mis datos?
No. Los datos se guardan localmente y se sincronizarán cuando recuperes la conexión.
¿Cuánto tiempo puedo usar la app sin conexión?
Indefinidamente. Todo el contenido cacheado está disponible mientras uses el navegador.
¿Qué pasa si actualizo la página sin conexión?
La app continuará funcionando con los recursos en caché. Este es el poder de las PWA.
¿Cómo sé cuándo vuelva la conexión?
Recibirás una notificación automática y la app se recargará para sincronizar cambios.
